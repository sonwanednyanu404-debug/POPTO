# POPTO — C Academic Module
## Lemon Inventory Management System

### Description
A struct-driven terminal application written in ANSI C demonstrating structured data management, inventory depletion calculations, input validation, and sales tracking for Maharashtra lemon orchards.

### Compilation
Using GCC / Clang / MSVC:
```bash
gcc main.c -o popto_inventory
./popto_inventory
```

### Features
- Struct-based storage (`LemonVariety`, `Inventory`)
- Formatted inventory reporting with pricing in INR (₹)
- Stock depletion & sale recording
- Dynamic addition of new harvest batches from Maharashtra districts
