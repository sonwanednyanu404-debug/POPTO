# POPTO — Java Academic Module
## Multi-Entity Lemon Marketplace Simulation

### Description
A Java 17+ simulation demonstrating class relationships (`Farmer`, `LemonProduct`, `Marketplace`), thread-safe synchronized stock reduction, farmer wallet payouts, and order settlement for the POPTO platform.

### Compilation & Execution
Using JDK / javac:
```bash
javac -d . Main.java
java popto.Main
```

### Key Concepts
- Encapsulation & Constructor initialization
- Synchronized methods for stock safety in multi-threaded environments
- Direct credit settlement simulation to farmer accounts
- Clean formatted catalog & checkout terminal display
